## Visual Identity

### Color Palette
| Color | Hex | Usage |
|---|---|---|
| Almost black (background) | `#0D0B09` | Main background — website & app |
| Cream (text) | `#EFE6D8` | Primary text on dark background |
| Dark espresso brown | `#3D2B1F` | Secondary background, cards |
| Warm tan/caramel | `#8A6F52` | Borders, icons, secondary text |
| Accent — terracotta/orange | `#D97A3F` | Buttons, CTAs, hover states |
| Muted green (optional secondary accent) | `#6B7A5E` | Optional — healthy/brunch context |

### Typography
- **Headings:** Cormorant Garamond (serif, elegant, echoes the logo)
- **Body:** Work Sans (clean, modern sans-serif)

### Brand Tone
**Cozy, Moody, Elevated**

### Design Constraints
- No animations — simple hover states only (color/shadow change)
- Mobile-first layout
- Static data only, no backend
